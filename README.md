🍜 A responsive restaurant web application for Coursera’s Module 5 Coding Assignment, featuring dynamic menu categories, reusable HTML snippets, AJAX-based content loading, and a randomized Specials category built with JavaScript.
# 🍜 JavaScript Module 5 Assignment

A responsive restaurant web application created for the **Module 5 Coding Assignment** of the Coursera course **HTML, CSS, and JavaScript for Web Developers** by Johns Hopkins University.

## 🎯 Assignment Objective

The website contains three home-page tiles:

- **Menu**
- **Specials**
- **Map**

JavaScript dynamically assigns a random menu category to the **Specials** tile. Each time the home page is loaded, clicking Specials may display a different category such as Lunch, Dinner, Sushi, Chicken, or Seafood.
